# Master en CSS: Responsive Design

Este proyecto es una página HTML diseñada para practicar y demostrar el uso de diferentes selectores CSS: universales, de etiqueta, de clase, de ID, de atributo, de hijo y de prioridad.
Nos guiamos atraves de una imagen puesta en la plataforma de camper que quede igual 

## Contenido

- index.html: Estructura principal de la página.
- estilos.css: Hoja de estilos con ejemplos aplicados de distintos tipos de selectores CSS.

## Características

- Diseño básico y estructurado con semántica HTML.
- Uso extensivo de selectores CSS para controlar estilos.
- Formulario estilizado con selectores de atributo.
- Ejemplo de estilos con prioridad usando `!important`.
